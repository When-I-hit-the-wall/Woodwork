# CLAUDE.md — Woodwork

Woodwork is a library of **calculation sheets** for timber structures (SIA 260, 261, 263, 265), written in Typst. A user copies the folder `woodwork/` (`woodwork.typ`, `lib/`, `data/`) once into the root of his Typst project, then copies the sheets he needs from `sheets/fr|de|en/` and changes a few values. Every check exists in a **standard** and a **detailed** version, in three languages, all **generated** from one source in `source/`. Woodwork's engine was taken from Woodcore on 4 November 2026 and lives on its own since; nothing links the two.

This file is the entry point and stays short. The reference is **`docs/`** — read [`docs/README.md`](docs/README.md) to find the file a task needs, and read only that.

## Core principles

- **One source of truth.** A sheet is written once, in `source/`; `sheets/` is generated by `tools/generate.py` and never edited by hand. A norm value is read from `woodwork/data/`, a word of the engine from `woodwork/lib/strings.json`, a sheet's label from `source/labels.json`. A copy that ages without saying so is the defect this project fears most.
- **Typst alone to use a sheet.** Compiling a sheet needs Typst 0.15.1 and nothing else. Python is for the maintainer's tools and tests only.
- **The engine stays inside `woodwork/`.** Nothing in `woodwork/` reads a path outside it; the engine reads its own files by paths relative to `lib/`, never `/woodwork/…`. Only a sheet imports `"/woodwork/woodwork.typ"`.
- **Norm values are read, never remembered.** Every value comes from a JSON of `woodwork/data/` that names its edition and page (`_source`); every clause a sheet cites is either one Woodcore already cited or read in the PDF of the norm at the time the sheet is written.
- **A refusal is a panic that names what is wrong.** An unknown argument, a missing variable, a unit of the wrong dimension, an unknown preset or strength class stops the compile with a message naming it and what would be accepted.
- **The engineer designs the command surface.** For a new command, argument or data shape, give him the options, their trade-offs and what each would lose; do not decide it silently.
- The full set of rules is [`docs/architecture/principles.md`](docs/architecture/principles.md) — read it before any change to the engine, the sheets or `data/`.

## How to handle a request

Classify every request first, and say in one line which mode you chose:

| Mode | When | What to do |
|---|---|---|
| **Question** | explanation, a value, how something works | Answer from `docs/` and the code. No workflow. |
| **Small change** | a fix or adjustment in one sheet or one engine function, no new command, argument or data shape | Follow the `small-feature` skill. No approval needed. |
| **Substantial change** | a new command or argument, a new family of sheets, a change to `data/`'s shape or to a rule of `docs/architecture/principles.md`, a dictated request | Follow the `big-feature` skill: spec in `docs/requirements/active/` → architecture review → **one approval** → implement → test → independent verification. |

To write or fix a sheet or the engine's Typst, read the `typst-sheet` skill (Woodwork's commands and traps) and, for Typst's own syntax, `typst-writing-document`.

## Non-negotiable working rules

- **Several Claude sessions may edit this repository at once.** Never `git checkout --`, `git stash`, `git reset` or `git clean`, not even on one path. Make targeted edits.
- **`sheets/` is generated.** Change `source/` or `source/labels.json`, then run `python tools/generate.py`; `tests/test_generate.py` fails when `sheets/` differs from what the generator writes.
- **Every text file is LF** (`.gitattributes`); Python writes with `encoding="utf-8", newline="\n"`. Prose is not hard-wrapped: one paragraph is one line. Code, docs and comments are in English; the specs and the talk with the engineer are in French.
- **A change is finished when its documentation is**: the `docs/` section it changed, a `CHANGELOG.md` entry, and for a command its section in `docs/typst/commands.md` with a compiling example.
- **Tests**: `python tests/run_tests.py [-k name | --related <files> | --failed]` from `Woodwork/` (`docs/conventions/testing.md`). Standard library only, and Typst on the `PATH`.
- **Commit at the end of each task** (the `finish` skill). The engineer authorised pushing Woodwork's work to `origin/main` (`git@github.com:When-I-hit-the-wall/Woodwork.git`, public); `finish` still asks once before each push.
- **The repository is public**: no norm PDF and no norm text copied beyond the tables of `woodwork/data/` (the engineer's decision D-13 of the founding spec).
