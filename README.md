# Woodwork

Calculation sheets for timber structures (SIA 260, 261, 263, 265), written in Typst, to copy into a project and adapt. Each check exists in French, German and English, in a standard and a detailed version.

Work in progress: the specification is `docs/requirements/active/2026-11-04-woodwork-feuilles-de-calcul.md`.

Woodwork's engine was taken from Woodcore on 4 November 2026 and lives on its own since. Licence: GPL-3.0 (see `LICENSE`).
