# Writing

- **Languages.** Code, comments, docs, commit messages: English. Specifications in `docs/requirements/` and the talk with the engineer: French. Sheets: three languages, generated (`source/labels.json`).
- **Line endings.** Every text file is LF (`.gitattributes`). Python writes text with `encoding="utf-8", newline="\n"`; never `write_text` without them.
- **Prose is not hard-wrapped.** One paragraph is one line, in every Markdown file and in every comment block.
- **A sheet's source** (`source/…/<check>.typ`): a heading written by hand with its label key (`= {title} (SIA 265)`), then one `#domain` whose arguments are the defaults of its lines; one named argument per line, indented with a tab under its command; every visible word is a key `{like-this}` of `source/labels.json` -- lower-case words joined by hyphens, **two at least**, so that a Typst code block of one word (`#{x}`) is never read as a key (one that the labels hold is refused); no `level`. The lines of calculation a standard and a detailed sheet share are written once in `source/parts/<name>.typ` and placed in both by a line `// @insert <name>`, so that each generated sheet stands alone.
- **Names.** Variable keys follow the engine's convention (`N_t_d`, `sigma_t_0_d`, `f_t_0_d`); file names are lower case with hyphens; in `source/`, file and folder names are English and `labels.json` gives their translations.
